Put it on your profile

In Discord

Discord only lets a Discord client set your presence, so photos and buttons reach your profile through the StatusC0rd app inside Discord. Open it once, leave it open, and it re-reads the card you saved here every five seconds. Nothing is installed.

The in-Discord app needs an application ID and a client secret. The instance owner adds both under Settings → Application & bot.

One-time setup in the Discord Developer Portal
  1. Activities → Settings → tick Enable Activities.
  2. Activities → URL Mappings → prefix /, target your-public-url/activity/.
  3. Keep the public URL in Settings pointing at the same HTTPS host — Discord fetches your photos from there.

Anyone who can install the app can launch it. Limit launch access with the allowed Discord IDs in Settings if this instance is not just for you.

Hosted separately

Split hosting

A bot worker on another machine owns the Discord connection and reads this card every few seconds. The status below is what that worker reports. The bot token stored under Settings → Application & bot is not used by this server while a worker is configured.

The keep-alive below cannot reach that machine: keep the worker awake on its own host. Setup: SETUP.md § 6.5.
