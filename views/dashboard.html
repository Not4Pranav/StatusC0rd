In Discord

Photos, the two lines of text, the timer and the buttons live on your profile, and Discord only lets a Discord client set them. The zero-install way is the built-in StatusC0rd app: it opens inside Discord, like a game, and pushes whatever you saved here — every five seconds, no rejoin.

The in-Discord app needs an application ID and a client secret. Add both under Settings → Application & bot.
  1. Make sure the app is installed on your server (invite it with the applications.commands scope).
  2. Join any voice channel and open the App Launcher, or run the app's Launch command.
  3. Leave the window open — it shows exactly what your friends see.

One-time setup in the Discord Developer Portal
  1. Activities → Settings → tick Enable Activities.
  2. Activities → URL Mappings → prefix /, target your-public-url/activity/.
  3. Keep PUBLIC_URL in this dashboard pointing at the same HTTPS host — Discord fetches your photos from there.

Anyone who can install the app can launch it. Limit launch access with ALLOWED_DISCORD_IDS if this instance is not just for you.

Advanced: run it on your computer instead (download, not needed for most people)

The local companion talks to the Discord desktop app over its local socket. It works offline from this dashboard and keeps the presence while the window is open, but it has to be installed and kept running — the in-Discord app above does not.

No Discord application ID is configured, so the companion cannot connect yet. Add it under Settings → Application & bot (Developer Portal → General Information → Application ID).
  1. Click Pair this computer.
  2. Double-click the download (Node.js 20+ and the Discord desktop app are required).
  3. Keep it running — it reconnects automatically if Discord restarts.

Where it shows

  • Bot card — name, type and status text, 24/7 on this server.
  • Your profile — photos, buttons and the timer while the in-Discord app is open.

Discord only lets a client set a user's photos and buttons, so those come from the in-Discord app (nothing to download) — or from the optional companion under My profile if you would rather run it locally.

Tips

  • Images are square-cropped automatically; 512×512 looks best.
  • The elapsed timer keeps counting between edits unless you tick “Restart from now”.
  • Presence updates are throttled to respect Discord's rate limits.
