Put this presence on your own Discord profile

Discord only shows text for bots — photos, buttons and the timer need to be pushed by your Discord client. Pair this computer and run the one-line command; it then follows whatever you set in this dashboard.

  1. Click Pair this computer.
  2. Copy the command and run it in a terminal (Node.js 18+).
  3. Keep it running — it reconnects automatically if Discord restarts.

Windows (PowerShell): curl.exe -fsSL "…" | node · macOS/Linux: curl -fsSL "…" | node. Prefer a file? Download the script. Keep the link private — it contains this device's pairing token.
