Three short steps. Everything is stored on this server — no file editing, no restarts.

  1. 1 Account
  2. 2 Discord app
  3. 3 Presence

Unlock setup

This instance is reachable from the internet, so setup needs the one-time token printed in the server logs (and saved in data/setup-token.txt).

Create your dashboard login

You will use this key to sign in. Pick something long — it protects the whole dashboard.

Connect your Discord app

Two values from the Developer Portal, and you are live: this is what puts photos, text and buttons on your own profile from inside Discord, with nothing to install.

Optional · a bot card that stays online 24/7

Bots can only show an activity name and one line of text, but that card stays up while you are offline. Create the token in Developer Portal → your app → Bot → Reset Token.

Design your presence

Change any of this later. Everything here — name, both lines, photos, buttons — lands on your own profile the moment you open StatusC0rd inside Discord.
