Your Discord presence, set up in the browser.

Text on a bot card that stays online 24/7. Photos, details and clickable buttons on your own profile. One dashboard drives both, and nobody has to open a config file.

{{PRIMARY_LABEL}} Free hosting guide

Costs nothing to run: one Discord application plus a free host. The guide walks through all three free options, start to finish.

Photos and buttons, nothing to install

Upload an image, type your lines, add up to two buttons, then open StatusC0rd inside Discord. It pushes the whole card to your real profile from a web page — no download, no terminal, no companion app.

A bot that never sleeps

The bot lives on your server, reconnects after network blips and keeps itself awake on free hosts, so the presence is there while you are not.

Everything from the website

First boot serves a three-step wizard: dashboard key, bot token, first presence with a photo. Keys are stored server-side and applied without a restart.

Edits land in seconds

Change the text, swap the picture, add a button — the dashboard preview matches Discord, and the paired computer picks the change up in about five seconds.

How it works

  1. Create a Discord application Copy the application ID and a bot token. Five minutes, no coding.
  2. Run it on a free host Render takes ten minutes; an Oracle Always Free VM makes it permanent.
  3. Open it inside Discord One click in the app launcher. The panel stays open and mirrors the dashboard.

What Discord does not allow

Bots can only broadcast a name, an activity type and a line of text — images and buttons are impossible on a bot account. Your own profile can show them, but only a Discord client may set them. StatusC0rd therefore ships as a Discord app too: the panel opens inside Discord itself, so the presence comes from your client without installing anything, and only while that panel is open.
